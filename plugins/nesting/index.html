Nesting Preview · 0.3.1

Pack copies of multiple G-code files onto a sheet by their outer shapes. Nothing is sent to the machine.

1 · Files

Add one or more G-code files. Set the copy count for each file below.

2 · Part
Add a G-code file in the Files tab. Each file is treated as one complete part.

Copies may be turned in steps of this angle (15° gives 24 orientations). A smaller step can pack tighter but takes longer. Parts are never mirrored.

Packing follows the part's outer shape, so a triangle can sit inverted beside another. Inner cuts do not affect packing. The path from the file, including its lead-in, counts as part of the shape.

3 · Layout

Edge to edge, between the parts' outer shapes. Kerf is not added; account for it in your post processor. The result reports the smallest gap actually achieved.

Compact picks the tightest block among results within 3% of the shortest length, then builds it outward from the selected origin corner. Shortest length may stagger parts to save a few mm, leaving gaps. Changing the origin corner requires Nest & generate again.

4 · Output

Corners are those of the nest frame: the tight bounding box of the placed parts (or the sheet you entered in maximum-parts mode). Custom coordinates are measured from its bottom-left, Y up. This only offsets the generated coordinates; it never zeroes or moves the machine. Zero your torch at the same point on the sheet.

Inner cuts are the ones inside another contour (holes). A cut is one torch cycle (M3/M4 … M5) or, in pen/knife files without those, one pen-down run that ends when the tool lifts to the highest Z. Each cut keeps its own approach, probe, pierce and pauses exactly as in the file; only the order changes. Files with a single cut are unaffected.

Estimate = cutting at each move's F word, rapids at this rate, plus G4 dwells. Z moves, probing and acceleration are not included, so treat it as a lower bound.

5 · Presets

Saved in UGS across sessions. Includes rotation, layout, gap and output settings, not the part. Use an existing name to replace it. Your last settings are also restored automatically.
