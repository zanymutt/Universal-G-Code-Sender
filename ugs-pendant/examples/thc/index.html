Reads/writes the SAME settings.csv the Sunton's SD card uses - parsed and built entirely in this browser, nothing uploaded anywhere. Loading a preset sends its whole settings group in one command; Add/Update capture the THC's current LIVE settings, never a typed value. Save settings.csv gives you the updated file to copy onto the SD card by hand.

minSpeed/maxSpeed/ultimateMax are stored as steps/s on the wire; shown and edited here in mm/min, matching the Sunton's own conversion. Needs at least one telemetry frame first so stepsPerMm is known.

Speed curve preview

speed = a·|ΔV|n + b, clamped to [min, ultimate max]

Live preview of the actual firmware formula (main.cpp's process(), not an approximation) - red dot = (min voltage, min speed), green dot = (max voltage, max speed). Updates as you type in the fields above, before you Send anything.

Rolling voltage (3s)

--

Raw plasma voltage, newest on the right, scrolling left as it ages past 3s - the y-axis auto-scales to whatever range the signal is actually in right now (tight at idle, widens as voltage rises), so smoothing/filtering changes here (Num averaged readings, Num realtime median samples, Exponential filter alpha) show up clearly instead of being lost against a fixed axis.
